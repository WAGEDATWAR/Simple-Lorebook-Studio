About

Lorebook Studio

Version 0.0.0

Lorebook Studio is local-first. Your projects never leave this device: there are no accounts, no analytics, and no uploads. Everything is stored in your browser and is only shared when you export or import a file yourself.

Getting started

Create and export your first lorebook

  1. Name your lorebook. The title field at the top names the active lorebook. Use the sidebar dropdown to switch between lorebooks or add a new one.
  2. Add entries. Choose New entry or From template, then fill in the title and content. Content is the text injected when the entry activates.
  3. Add trigger keys. Type keys as chips: press Enter or comma to add, paste a comma-separated list, or write /pattern/i for a regex key. Always-on entries skip key matching.
  4. Organize and search. Add tags to entries and lorebooks, filter the list by tag or status, and use search to highlight matches and see why an entry matched.
  5. Check for problems. Open Issues to find empty content, duplicate or colliding keys, invalid regex, missing keys, unreachable entries, and insertion-order collisions.
  6. Save and back up. Changes save to your browser automatically. Export a project backup regularly, or use Save to write a project file when your browser supports it.
  7. Export for your frontend. Open Export for SillyTavern World Info, Chub, character book, or native output. Unknown imported fields are preserved for round-trips.
